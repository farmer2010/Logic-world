# Logic-world

## Игровой процесс

Поле разбито на клетки. В каждой клетке может находиться блок. Блоки взаимодействуют друг с другом
### Блоки:

![](https://github.com/farmer2010/Logic-world/blob/main/README%20images/wire.png) **Провод** - передает сигнал. Активируется мгновенно

![](https://github.com/farmer2010/Logic-world/blob/main/README%20images/activator.png) **Активатор** - передает сигнал во все стороны, если активен. Можно переключать нажатием мыши

**Логическое НЕ** - передает сигнал вперед, если не получает сигнал сзади

**Логическое И** - передает сигнал вперед, только если получает два сигнала с боковых входов

**Логическое Исключающее ИЛИ** - передает сигнал вперед, только если получает один сигнал с боковых входов

**Ячейка памяти** - передает вперед сохраненный сигнал. Если получает на левый вход сигнал, то запоминает сигнал с правого входа

**Распределительная коробка** - передает горизонтальные и веримкальные сигналы отдельно

**Защищенный провод** - провод, соединяющийся только с двумя блоками. Можно изменять соединения через WASD

**Кнопка** - при нажатии выдает кратковременный сингнал во все стороны

**Диод** - пропускает сигнал только в одном направлении

**Детектор** - передает сигнал вперед, если блок за детектором содержит сигнал. Передача сигнала не зависит от состояния блока за детектором

![](https://github.com/farmer2010/Logic-world/blob/main/README%20images/lamp.png) **Лампа** - активируется при подаче сигнала. При активации всех ламп на уровне он считается пройденным

**Стекло**(доступно к установке только в редакторе) - не дает ставить, ломать и редактировать блоки под собой

**Поршень** - сдвигает блоки перед собой

**Липкий поршень** - сдвигает блоки перед собой. Возвращает один блок перед собой на место, если тот стоял вплотную к выдвижной части поршня

**Несдвигаемый блок** - не двигается поршнем

**Кирпичи** - декоративный блок. Ничего не делают

Цель игры - активировать все установленные на уровне лампы

## Управление

**ЛКМ** - Ставить блок, нажать на блок

**ПКМ** - Ломать блок

**Q** - Пипетка. Выбирает в "руку" блок под курсором

**R** - Повернуть блок в "руке"

**Колесико** - Выбор в "руку" блока из инвентаря

**V** - Отразить блок(только для ячейки памяти)

**W, A, S, D** - Изменение состояния защищенного провода

**T** - Открыть/закрыть инвентарь

**ESC** - Закрыть меню
